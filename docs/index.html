Bad Shrooms Command Center

One setup step on this phone. The desk data lives in a private GitHub repo, and this page needs a token to read and write it.

  1. Open https://github.com/settings/personal-access-tokens/new
  2. Name it Command Center and pick an expiry you can live with.
  3. Repository access: Only select repositories, then badshrooms-desk-data.
  4. Permissions: Repository permissions, Contents: Read and write.
  5. Press Generate token, copy it, and paste it below. It stays on this phone.
